<h1 align="center">Flickbase Movie Database</h1>


Flickbase is a movie search database that allows the user to search for any movie. 


<h2 align="center">Stack Used</h2>
*React <br/>
*Javascript <br/>
*CSS<br/>
*HTML

<h2 align="center">Main Features</h2>
*Search bar that allows the user to enter any keyword and the API will return the 6 most popular movies with that word in their title. <br/>
*Sorting function that allows the user to sort alphabetically or reverse alphabetically. <br/>
*Dedicated page for each movie with MPAA Rating, Release Date, IMDB Rating, and a short summary.
